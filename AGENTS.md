# Agent Rules

Read [CLAUDE.md](CLAUDE.md) for project context, and [STATE.md](STATE.md) for where things stand.

1. **Planning only, for now.** Don't write site, API, or database code until the project owner explicitly says to start building.
2. **Only agreed items go in the docs.** Raise new methods, tools, features, or details as clearly labeled proposals, and ask first. Don't write them in as if they were decided.
3. **Go one step at a time.** Let the owner review between steps.
4. **Course ↔ career logic is a separate step.** Don't propose or build matching or scoring logic until that step is opened.
5. **No paid services.** Don't sign up for paid services or plans before the faculty budget discussion.
6. **Leave git alone.** Another agent is handling version control.
7. **Put files where they belong.** Follow the folder layout in CLAUDE.md, and read a folder's README before adding to it.
8. **Keep the docs current.** When you finish work, update STATE.md, and update ROADMAP.md if a phase changes.
